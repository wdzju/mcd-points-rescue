三步跑完，你自己的那份

麦当劳 MCP 的登录是手机号 + 短信验证码 —— 那是你的真实身份凭证。 所以清算局不做登录系统：你自己拿 Token，它只负责引导、保管和使用，全程不出本机。

配置一次

运行 --setup，它会告诉你去哪点、拿什么。Token 存本机并收紧权限，不写入仓库、不上传。

自检一遍

--doctor 逐项确认：Token、连接、账户、券池、抽奖、历史订单、门店。哪里不通直接说。

出报告

--live --city 你的城市。生成单文件 HTML，也可以导出 Markdown 清单直接照着操作。
