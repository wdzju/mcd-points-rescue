三步接上你的积分

麦当劳 MCP 的登录是手机号 + 短信验证码 —— 那一步必须发生在麦当劳自己的页面上， 这是凭证安全的底线。剩下的三步，全部在这页完成。

1去官网拿 Token

点下面的按钮会在新窗口打开麦当劳官方 MCP 平台。请确认地址栏是 open.mcd.cn，然后按页面提示操作。

  1. 右上角 登录 → 用手机号完成短信验证
  2. 右上角 控制台
  3. 点 激活，同意服务协议
  4. 复制生成的 Token
打开 open.mcd.cn（新窗口）
为什么不做成页面内直接登录？
在第三方页面里让用户输入麦当劳账号的手机号和短信验证码，形态上与钓鱼页面无法区分 —— 用户无从确认验证码交给了谁。所以这一步刻意留在官网：你能在地址栏验证域名， 而本页只负责接收你自愿粘贴回来的 Token。

2粘贴回来

Token 会保存在你本机，权限收紧为仅本人可读写，不会写入仓库，也不会发送到任何地方。

3跑一次分析

会实时读取你的积分、商城券池、抽奖活动、历史订单，并按你所在城市的门店菜单价格做估值。
